# Páginas web

> **En pocas palabras:** Aquí se documentan las páginas secundarias de la web y la forma de enlazarlas con la portada. Al crear o mover una página, revisa las rutas relativas, los enlaces de vuelta, el título y la adaptación a móviles. No basta con que el archivo HTML exista: hay que comprobar que se puede abrir desde la web publicada.

Crea aquí páginas independientes como `ciudades.html`, `personajes.html` y `como-jugar.html`. Mantén la navegación y las rutas relativas actualizadas.
