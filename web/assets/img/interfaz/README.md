# Imágenes de interfaz

- `icono-arcane.svg`: fuente canónica del favicon del juego y la web. El manifiesto de arte copia este archivo hacia `src/icono-arcane.svg` al empaquetar.
- `icono.png`: icono rasterizado usado por el empaquetado de escritorio.

El favicon público se enlaza como `icono-arcane.svg` desde `web/index.html`; el generador conserva el mismo archivo en la raíz de `web-dist/`.
