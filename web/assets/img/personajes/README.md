# Retratos de personajes

Retratos WebP sincronizados desde `src/img/arte/caras/`. El juego mantiene los originales en su estructura y la web utiliza estas copias con rutas propias bajo `assets/img/personajes/`.

Los nombres de archivo son IDs de personaje en minúsculas; al añadir uno, actualiza también el índice público y la validación de recursos.
