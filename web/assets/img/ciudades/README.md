# Imágenes de las ciudades

Los archivos de `piltover/` y `zaun/` se han preparado a partir de los ZIP `PILTOVER.zip` y `ZAUN.zip`, conservando imágenes y temporadas en nombres claros para la web pública.

- `piltover/`: panoramas T1/T2, Academia, Taller de Jayce, Consejo, Ejecutores, Mansión Kiramman, Plaza, Artesanos, Hexpuertas, Stillwater y puente.
- `zaun/`: centro, ciudad subterránea, mercado, Muelles, Fábrica/Laboratorio, La Última Gota, comuna de Viktor, escondite de Jinx y Luciérnagas.

La web se sirve desde `web-dist/assets/img/ciudades/`; no se deben apuntar páginas públicas a rutas que existan solo dentro de `src/`.
