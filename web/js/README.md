# JavaScript de la web

> **En pocas palabras:** Esta carpeta está reservada para el JavaScript de la web, no para la lógica interna del juego de escritorio. Mantén las responsabilidades separadas y comprueba que los scripts cargan desde las rutas correctas. Si una función visual no está conectada a una acción real, descríbela como maqueta o pendiente.

Guarda aquí solo código de la web. Usa `app.js` como punto de entrada y separa componentes por responsabilidad. El motor del juego vive en `src/js/`.
